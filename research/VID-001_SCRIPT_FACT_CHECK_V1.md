- a location;
- a real construction date;

## Editorial note

The script contains many numbers in the first third. During timed narration testing, consider whether the U.S. Berkeley forecast paragraph can be shortened or moved to on-screen text if it slows the story. Removing a supported statistic for pacing is acceptable; adding an unsupported statistic is not.
