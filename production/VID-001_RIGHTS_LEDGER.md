## Source-data notes

### IEA
Primary report:
https://www.iea.org/reports/key-questions-on-energy-and-ai

The report page lists CC BY 4.0. The project redraws the values rather than embedding an IEA chart screenshot.

### Berkeley Lab
VID-001 uses source facts and original graphics. Do not assume every report figure is public domain. Original redrawing avoids unnecessary ambiguity.

The 2025 Update is listed by DOE as CC BY 4.0, but the project still uses an original chart design with citation.

### Utility pages
PGE and ATC are factual references. The project does not use their logos, screenshots, or reproduced proprietary graphics.

## Asset-entry rule

Before importing an external media file into the final edit, record:
- creator/provider;
- exact asset URL or library ID;
- acquisition date;
- license;
- whether commercial YouTube use is allowed;
- attribution requirement;
- restrictions;
- file name used in project.

“No attribution required” still needs a recorded source/license.
