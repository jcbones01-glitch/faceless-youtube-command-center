## Source-data notes

### IEA
Primary report:
https://www.iea.org/reports/key-questions-on-energy-and-ai

The report page lists CC BY 4.0. Prefer redrawing values rather than embedding an IEA chart screenshot.

### Berkeley Lab
VID-001 uses source facts and original graphics. Do not assume every Berkeley report figure is public domain. The Speed to Power report includes a copyright notice and U.S.-government license language; original redrawing avoids unnecessary ambiguity.

The 2025 Update is listed by DOE as CC BY 4.0, but the project still prefers original chart design with citation.

### Utility pages
PGE and ATC are factual references. Do not use logos, website screenshots, or reproduced proprietary graphics unless a specific need arises and reuse rights are verified.

## Asset-entry rule

Before importing an external media file into the final edit, record:
- creator/provider;
- exact asset URL or library ID;
- acquisition date;
- license;
- whether commercial YouTube use is allowed;
- attribution requirement;
- restrictions;
- file name used in project.

“No attribution required” still needs a recorded source/license.
