# VID-001 Rough-Cut Assembly Checklist V1

## Before edit

- [ ] Clean narration script is the only spoken-script source.
- [ ] Review script remains available for claim IDs.
- [ ] Actual narration runtime recorded.
- [ ] Any narration edits that change factual meaning are re-checked against source ledger.
- [ ] All external media entered in rights ledger.

## Audio

- [ ] Record/generate 35–50 second voice sample first.
- [ ] Confirm technical pronunciations.
- [ ] Record full narration.
- [ ] Remove obvious mouth noise/clicks only as needed.
- [ ] Avoid aggressive compression that sounds artificial.
- [ ] Background music, if any, sits below narration and has verified license.
- [ ] No constant “epic” soundtrack required.

## Picture assembly

- [ ] Build core grid diagram first.
- [ ] Build IEA chart.
- [ ] Decide whether U.S. LBNL range chart helps pacing or should be omitted.
- [ ] Build connection-vs-interconnection animation.
- [ ] Build six-question overlay.
- [ ] Build PGE process flow.
- [ ] Build ATC example timeline with permanent disclaimer.
- [ ] Build forecast-risk illustration.
- [ ] Build flexibility four-part visual.
- [ ] Build power-vs-energy battery visual.
- [ ] Build final three-question recap.

## Fact integrity

- [ ] “2025” and “2030 projection” labels visible on IEA graphic.
- [ ] AI-focused demand not confused with total data-center demand.
- [ ] LBNL range, if shown, labeled modeled scenarios / not confidence interval.
- [ ] PGE example named.
- [ ] ATC example named and “not U.S. average” visible.
- [ ] Fictional project marked illustrative near first appearance.
- [ ] No stock footage caption implies it depicts the fictional project.
- [ ] MW and TWh not interchanged.
- [ ] Batteries not presented as creating energy.
- [ ] Flexibility not presented as universal.

## Pacing review

At first rough cut, inspect:
- [ ] Is the “where do you plug it in?” question reached almost immediately?
- [ ] Does the first statistic come only after the physical problem is clear?
- [ ] Can any number be moved on-screen rather than spoken?
- [ ] Does every major diagram change teach something?
- [ ] Are there decorative cuts that interrupt comprehension?
- [ ] Is any section repeating a point already understood?
- [ ] Does the payoff arrive before the CTA/sequel tease?

## Mobile review

Watch once:
- [ ] on phone speaker;
- [ ] with captions on;
- [ ] at normal brightness;
- [ ] without pausing.

Check:
- text size;
- chart labels;
- dialogue intelligibility;
- thumbnail legibility;
- subtitle line breaks.

## Final export gate

Do not publish until:
- [ ] source ledger reconciled;
- [ ] rights ledger reconciled;
- [ ] thumbnail/title selected;
- [ ] description includes primary sources;
- [ ] no placeholder footage/text remains;
- [ ] actual export watched end-to-end;
- [ ] audio peaks/clipping checked;
- [ ] upload is reviewed privately/unlisted before public release.
